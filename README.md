# Mood Detection API

## 🚀 Project Overview

The **Mood Detection API** is an AI-powered web service that classifies text inputs into different emotional states, such as **sadness**, **joy**, **love**, **anger**, **fear**, and **surprise**. This project uses a pre-trained deep learning model (fine-tuned for emotion detection) to analyze input text and return the predicted mood along with a confidence score.
